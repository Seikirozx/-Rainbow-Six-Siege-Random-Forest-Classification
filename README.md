1. หลักการและเหตุผล  
ปัจจุบันอุตสาหกรรมเกมและกีฬาอีสปอร์ต (E-Sports) มีการเติบโตอย่างรวดเร็ว โดยเกมแนว Tactical 
Shooter อย่าง Rainbow Six Siege เป็นหนึ ่งในเกมที่มีความซับซ้อนสูงและต้องอาศัยกลยุทธ์ในการเล่นอย่างมาก      
ปัจจัยที่ส่งผลต่อชัยชนะไม่ได้มีเพียงแค่ความแม่นย าในการยิง แต่ยังรวมถึงการเลือกแผนที่ (Map)                  
การเลือกจุดป้องกัน (Objective Location) และระยะเวลาในการเล่นแต่ละรอบ (Round Duration) 
การน า Open Dataset ที่บันทึกประวัติการแข่งขันของผู ้เล่นมาท าการวิเคราะห์ข้อมูล (Data Analysis)                
จึงมีความส าคัญอย่างยิ ่ง เพราะจะช่วยให้เราเห็นภาพรวมและแนวโน้มว่าปัจจัยแวดล้อมใดในเกมที่ส่งผลให้ฝ่าย
บุก (Attacker) หรือฝ่ายรับ (Defender) มีความได้เปรียบมากกว่ากัน โครงงานนี ้จึงได้นำข้อมูลดังกล่าวมา
วิเคราะห์และประยุกต์ใช้ร่วมกับเทคนิค Machine Learning เพื่อค้นหาความสัมพันธ์ที่ ซ่อนอยู่และทำนายผลลัพธ์ของการแข่งขัน

2.วัตถุประสงค์ 
1. เพื่อศึกษารูปแบบและวิเคราะห์ปัจจัยแวดล้อม (เช่น แผนที่, จุดภารกิจ) ที่ส่งผลต่อความได้เปรียบ
เสียเปรียบของฝ่ายบุกและฝ่ายรับในเกม Rainbow Six Siege 
2. เพื่อสร้างโมเดล Machine Learning ในการทำนายผลแพ้ชนะ (Win Role) ของแต่ละรอบการแข่งขัน 
โดยใช้อัลกอริทึม Random Forest Classification
3.  ผลงานที่ผ่านมา 
ในปัจจุบันมีการนำเทคนิค Machine Learning มาใช้ในการวิเคราะห์และทำนายผลการแข่งขัน E-Sports อย่าง
แพร่หลาย เช่น การวิเคราะห์ปัจจัยที่มีผลต่อการชนะในเกมแนว Tactical Shooter อย่าง CS:GO หรือ Valorant 
    งานวิจัยส่วนใหญ่มักใช้อัลกอริทึมกลุ่ม Classification เช่น Decision Tree, Logistic Regression หรือ Random 
Forest ในการแบ่งแยกผลลัพธ์ (ชนะ/แพ้) จากตัวแปรต่างๆ เช่น สถิติการยิง หรืออาวุธที่เลือกใช้ โครงงานนี ้จึง
ได้น าแนวคิดดังกล่าวมาประยุกต์ใช้ แต่ปรับเปลี่ยนมุมมองโดยมุ่งเน้นไปที่ปัจจัยด้าน "สภาพแวดล้อม" ได้แก่ 
แผนที่ (Map) ตำแหน่งเป้าหมาย (Objective Location) และระยะเวลาของรอบนั้นๆ ในเกม Rainbow Six Siege 
เพื่อดูว่าอัลกอริทึม Random Forest จะสามารถวิเคราะห์ความได้เปรียบเสียเปรียบและท านายผลได้ดีเพียงใด 
5. การพัฒนาระบบ 
การพัฒนาระบบในโครงงานนี ้แบ่งออกเป็น 3 ขั ้นตอนหลัก ได้แก่ การเตรียมข้อมูลเบื ้องต้น การน าเสนอข้อมูล
ด้วยกราฟ และการสร้างโมเดล Machine Learning โดยมีการเขียนโปรแกรมด้วยภาษา Python ผ่าน Google 
Colab ดังนี้
การนำเข้าและเตรียมข้อมูล (Data Preprocessing) ขั้นตอนแรกคือการเรียกใช้ไลบรารีที่จำเป็น และนำเข้า
ข้อมูล Open Dataset ที่เป็นไฟล์ .csv จากนั้นทำการลบข้อมูลที่มีค่าว่าง (Missing Values) ออกเพื่อให้พร้อม
สำหรับการวิเคราะห์
